# Project requirements for local development

# Core toolchain
Flutter SDK (Dart 3.8+)

# Platform tooling
Android Studio (Android SDK + emulator)
Xcode (for iOS builds on macOS)

# Services
Firebase project (Android/iOS configured)
Cloudinary account (cloud name + upload preset)
MapTiler account (API key)

# Project setup
Copy .env.example to .env and fill required keys

# Downloads the libraries in pubspec.yaml
Run: flutter pub get
